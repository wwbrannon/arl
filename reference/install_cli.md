# Install the Arl CLI wrapper

Prints platform-appropriate instructions for making the packaged CLI
wrapper available from the shell. No files are written or copied – the
user follows the printed instructions themselves.

## Usage

``` r
install_cli(quiet = FALSE)
```

## Arguments

- quiet:

  If `TRUE`, suppress printed instructions and return the script path
  invisibly.

## Value

The path to the CLI wrapper script, invisibly.
